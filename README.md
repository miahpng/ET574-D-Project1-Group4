
# Study Session Tracker

## Project Description

The Study Session Tracker is a console-based Python program
for recording and reviewing study sessions.

## Features

- Add a study session
- Record the subject, study duration, location, and notes
- View all recorded study sessions
- View a summary of study activity
- Calculate total sessions, total minutes, average duration,
  longest session, and shortest session
- Validate user input

## Project Files

- `main.py` - Displays the menu and controls program flow.
- `tracker.py` - Contains functions for adding and viewing sessions.
- `data.py` - Stores session information in parallel lists.

## Requirements

- Python 3
- GitHub Codespaces or a local Python environment

## How to Run

1. Open the project in a terminal.
2. Run:

   ```bash
   python main.py
   ```

3. Choose an option from the menu.
4. Follow the prompts to record or view study sessions.

## Data Storage

Session data is stored in parallel Python lists in memory.
The data is not saved permanently after the program exits.
